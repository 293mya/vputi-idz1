# Оценка проекта по требованиям ИДЗ1

Дата сверки: 19 ноября 2026 года.

Источник требований: презентация курса `2026-11-05-day-01-storyboard.pdf`, страницы 4, 5, 13, 49 и 50.

## Что действительно требуется

| Требование ИДЗ1 | Состояние проекта |
| --- | --- |
| Локально запускаемый проект | Выполнено: `npm install`, затем `npm run dev` |
| Работающий основной сценарий | Выполнено: вход, добавление поездки, PDF, список, редактирование и удаление |
| Сохранение данных после перезапуска | Выполнено: поездки, PDF и демосессия сохраняются в IndexedDB |
| README с запуском | Выполнено |
| Архив проекта | Выполнено |
| Архив без `node_modules` и ключей | Выполнено и проверено |
| Краткая рефлексия | Выполнено в `REFLECTION.md` |
| PRD, сценарий и DESIGN.md | Выполнено |

Публикация, Git, CI/CD и обязательные тесты относятся к следующему этапу — ИДЗ2. Сервер и настоящая база данных для ИДЗ1 не обязательны: материалы курса прямо разрешают хранение данных в браузере.

## Что сделано сверх требований

- IndexedDB вместо `localStorage`, включая хранение PDF как `Blob`;
- адаптивный React-интерфейс и компонентные библиотеки;
- демовход с несколькими состояниями;
- редактирование, удаление, сортировка и ближайшая поездка;
- локальное чтение текстового PDF с подтверждением перед заполнением;
- одиннадцать автоматических проверок;
- production-сборка и подготовка клиентских маршрутов к будущей публикации;
- проверка production-зависимостей на известные уязвимости.

## Стоимость возможных расширений

Оценки даны как объём разработки одного человека. Стоимость внешних сервисов зависит от выбранного провайдера и количества запросов.

| Расширение | Оценка времени | Внешние расходы | Решение для ИДЗ1 |
| --- | ---: | ---: | --- |
| Чтение текстового PDF и подтверждение | 4–8 часов | 0 | Реализовано локально |
| OCR для фотографий и сканов | 1–2 дня | 0 при локальном OCR; увеличится размер приложения | Оставить следующим этапом |
| Проверка авиационного рейса через API | 2–5 дней | Обычно бесплатный лимит или платный тариф | Не добавлять без сервера и ключа |
| Проверка поездов и автобусов | От 1 недели | Зависит от перевозчиков и стран | Не добавлять в ИДЗ1 |
| Серверная база и разделение данных по пользователям | 3–7 дней | Возможен бесплатный стартовый тариф | Не требуется для ИДЗ1 |
| Email/пароль с регистрацией и восстановлением | Ещё 2–4 дня | Зависит от сервиса писем | Только вместе с серверной базой |
| Google OAuth | Ещё 1–2 дня | Обычно 0 на учебном объёме | Требует опубликованного адреса и настройки OAuth |
| Дополнительный онбординг | 4–8 часов | 0 | Низкий приоритет перед сдачей |
