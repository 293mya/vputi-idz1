# впути

Локальное React-приложение для хранения данных поездок и PDF-билетов.

Текстовые PDF обрабатываются локально: приложение может предложить маршрут, дату и время, но подставляет их только после подтверждения пользователя. Сканы и неподдерживаемые форматы заполняются вручную.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://127.0.0.1:4173/`. Используйте тот же адрес и профиль браузера: IndexedDB привязана к origin.

Демонстрационный вход:

- почта: `demo@vputi.test`;
- пароль: `Vputi2026!`.

## Проверка сборки

```bash
npm test
npm run build
```

`npm test` проверяет сохранение поездки вместе с PDF, обновление, замену PDF, удаление, демонстрационную сессию, сортировку, группировку, расчёт длительности и разбор текста билета.

## Материалы для сдачи

- `PRD.md` — идея, границы и основной сценарий;
- `DESIGN.md` — дизайн-система и применение референсов;
- `SELECTED_CONCEPT.png` — выбранный концепт;
- `REFLECTION.md` — рефлексия по работе;
- `VIDEO_SCRIPT.md` — сценарий итогового видео.

Архитектура клиентской веб-версии описана в `ARCHITECTURE.md`.
Итоговый технический и ручной прогон зафиксирован в `QA.md`.
Сверка с исходными требованиями курса и оценка следующих этапов находятся в `ASSESSMENT.md`.

Тестовый PDF без личных данных находится в `output/pdf/demo-travel-ticket.pdf`.
