# Архитектура хранения «впути»

Статус: фактическая реализация на 19 ноября 2026 года.

## Границы этапа

«впути» — клиентское React SPA без сервера и удалённой базы. Поездки, PDF и признак демонстрационного входа хранятся в IndexedDB текущего браузера. Серверная авторизация и синхронизация между устройствами в этот этап не входят.

Фиксированный origin: `http://127.0.0.1:4173`. IndexedDB изолирована по scheme, host и port, поэтому между запусками нужно использовать тот же адрес.

## Модули

| Файл | Ответственность |
| --- | --- |
| `src/App.jsx` | Экраны, формы, маршруты, React-состояние и жизненный цикл `blob:` URL |
| `src/storage.js` | Открытие IndexedDB и транзакции поездок и демонстрационной сессии |
| `src/demoAuth.js` | Тестовая пара и проверяемые состояния формы демовхода |
| `src/tripUtils.js` | Порядок будущих и прошедших поездок, группировка, ближайшая поездка, расчёт длительности и форматирование остановок |
| `src/ticketScanner.js` | Локальное извлечение текста PDF, OCR первой страницы скана и подготовка подтверждаемой подстановки |
| `src/placeSearch.js` | Мировой поиск аэропортов и станций через Photon/OpenStreetMap |
| `src/routeStops.js` | Подсчёт промежуточных остановок по Transitland: сначала без ключа, затем с ключом при требовании сервиса |
| `src/main.jsx` | React-корень, тема, локаль и `BrowserRouter` |
| `tests/*.test.js` | Проверка хранилища, Blob, демовхода, сортировки, группировки и длительности |

## IndexedDB

База: `vputi`, версия 9. Object store `trips` использует `keyPath: "id"`; `settings` хранит только булев признак демонстрационного входа под ключом `authenticated`. Почта и пароль в базу не записываются.

### Запись `trips`

| Поле | Тип | Назначение |
| --- | --- | --- |
| `id` | `string` | UUID и ключ записи |
| `transport` | `train \| plane \| bus` | Вид транспорта |
| `originCity`, `destinationCity` | `string` | Города |
| `originPlace`, `destinationPlace` | `string` | Аэропорт, вокзал или остановка |
| `originAddress`, `destinationAddress` | `string` | Необязательные адреса |
| `date`, `arrivalDate` | `string` | Даты `YYYY-MM-DD`; прибытие может быть пустым |
| `time`, `arrivalTime` | `string` | Время `HH:mm`; прибытие может быть пустым |
| `stopsCount` | `number \| null` | Число промежуточных остановок для поезда; для других видов транспорта `null` |
| `travelNumber` | `string` | Необязательный номер рейса или поезда |
| `terminal`, `platform` | `string` | Необязательные терминал и платформа либо путь |
| `ticketName` | `string` | Имя PDF |
| `ticketBlob` | `Blob` | Бинарные данные PDF |

`ticketUrl` существует только в React-состоянии. `saveTrip` исключает его перед `put`.

## Потоки данных

### Запуск

1. `App` читает признак демовхода из `settings`.
2. После входа `TripsApp` вызывает `loadTrips()`.
3. Хранилище выполняет `getAll()` в read-only транзакции.
4. Из каждого `ticketBlob` создаётся новый `blob:` URL.
5. Карточка открывает URL в новой вкладке.
6. `sortTripsForDisplay()` ставит будущие поездки первыми, а завершённые — ниже в обратной хронологии. `isTripPast()` использует прибытие, а при его отсутствии — отправление.

### Добавление и редактирование

1. После выбора файла `pdfjs-dist` локально извлекает текстовый слой PDF.
2. Парсер предлагает поддерживаемые значения, но форма меняется только после подтверждения пользователя.
3. Форма проверяет поля, формат, лимит PDF в 10 МБ и целое число остановок от 0 до 99 для поезда.
4. `saveTrip()` выполняет `put()` в read-write транзакции.
5. React-состояние меняется только после завершения транзакции.
6. При замене PDF старый URL отзывается, а новый создаётся из нового Blob.
7. При ошибке форма сохраняет введённые данные, показывает ошибку и кнопку «Повторить сохранение».
8. Для PDF без текстового слоя `tesseract.js` распознаёт первую отрендеренную страницу локально.

### Подсказки мест и отображение участка поезда

Когда введено не менее двух символов, `PlaceAutocomplete` с задержкой 350 мс запрашивает Photon/OpenStreetMap для поездов и самолётов. Результаты кэшируются в памяти вкладки; при недоступности сети интерфейс показывает локальный каталог и объясняет переключение. Выбор результата подставляет город, место, адрес и координаты. Для поездов `routeStops.js` обращается к Transitland и суммирует `intermediateStops` в железнодорожных сегментах. Сначала запрос выполняется без ключа; если сервис требует авторизацию, поле остаётся ручным и форма сообщает об этом. Введённое вручную число не перезаписывается ответом маршрута. Карточка показывает `stopsCount` между точками маршрута; длительность выводится один раз над карточкой.

### Удаление

`removeTrip()` выполняет `delete(id)`. После успешной транзакции React убирает карточку и отзывает её URL. При ошибке карточка остаётся в интерфейсе.

### Освобождение URL

`URL.revokeObjectURL()` вызывается при замене PDF, удалении поездки и размонтировании `App`.

## Ограничения

- Данные привязаны к одному origin и профилю браузера.
- Очистка данных сайта удаляет поездки и PDF.
- Приватный режим может очистить базу после закрытия окна.
- Общий лимит хранилища зависит от браузера и свободного места.
- OCR первой страницы работает локально и требует загрузки языковых данных Tesseract при первом запуске.
- Распознанные значения не считаются проверенными и всегда требуют сверки с билетом.
