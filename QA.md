# Итоговая проверка «впути»

Дата проверки: 19 ноября 2026 года.

## Автоматические проверки

- `npm test`: 15 проверок пройдены в четырёх тестовых файлах.
- `npm run build`: production-сборка Vite создана успешно.
- `npm audit --omit=dev`: известных уязвимостей в production-зависимостях не найдено.
- `dist/index.html` и статические ресурсы создаются; `public/_redirects` попадает в сборку и обеспечивает возврат SPA на `index.html` для прямых маршрутов после публикации.

## Ручная проверка в браузере

| Сценарий | Результат |
| --- | --- |
| Неверная пара демовхода | Показывается ошибка, приложение не открывается |
| Состояния входа | Различаются пустые поля, формат почты, неизвестный пользователь, неверный пароль, загрузка и ошибка хранилища |
| Корректный демовход | Открывается экран «Мои поездки» |
| Обновление страницы | Вход и поездки восстанавливаются из IndexedDB |
| Выход и повторный вход | Поездки сохраняются |
| Пустая форма | Все обязательные поля получают сообщения об ошибках |
| Добавление | Обезличенный PDF и маршрут Барселона — Лондон сохраняются |
| Чтение PDF | Найдены BCN–STN, 1 декабря 2026 и 06:20; форма не меняется до подтверждения |
| Подтверждение распознавания | После действия пользователя маршрут, адреса, дата и время подставлены; показана просьба сверить PDF |
| Ручной сценарий | При отсутствии поддерживаемого текста PDF остаётся прикреплённым, поля доступны вручную |
| Сбой OCR | Доступна кнопка повторного распознавания; ручной ввод остаётся доступным |
| Длительность | Для 14:30–17:00 показано «2 ч 30 мин» |
| PDF после обновления | Из сохранённого Blob создаётся новый `blob:` URL |
| Редактирование | Форма заполнена; изменённое поле отмечено; исходная карточка обновляется без дубликата |
| Удаление | Меню и диалог подтверждения открываются; удаление записи покрыто автоматическим тестом |
| Адаптивность | Проверены ширины 320 и 1280 px; горизонтального переполнения нет |
| Прямой маршрут редактирования | `/edit/:tripId` открывается после обновления при сохранённом входе |
| Уход из формы | Нижняя навигация открывает диалог, который позволяет остаться или отбросить изменения |

## Соответствие критериям

- реализованы поезд, самолёт и автобус;
- предстоящие и прошедшие поездки разделяются до группировки по дате;
- ближайшая будущая поездка определяется отдельно от прошедших;
- PDF до 10 МБ хранится как `Blob`, а временный URL не записывается в базу;
- обязательные поля, формат PDF и порядок времени проверяются;
- адреса и прибытие остаются необязательными;
- редактирование, замена PDF и удаление работают через одну запись по `id`;
- демовход хранит только булев признак, без почты и пароля;
- данные не покидают браузер и не синхронизируются между устройствами;
- локальный запуск для видео сохранён через `npm run dev`.

Исходники опубликованы в открытом репозитории: <https://github.com/293mya/vputi-idz1>. Проект подготовлен как React SPA: при размещении на хостинге потребуется production-сборка и правило возврата `index.html` для клиентских маршрутов.
